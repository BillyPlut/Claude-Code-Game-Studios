Solo indie developer on Altyn Adam. Strong game design background — arrives with design intent already formed, referencing RDR2, Ghost of Tsushima, AC2 as influences. Prefers Russian language for communication but writes design prompts in English.

Uses the game-designer agent as a gap-finder and critic, not as an ideator. Presents decided facts and asks for: design gaps, anti-patterns, degenerate strategy checks, and concrete tradeoff questions. Does not need the full question-first workflow when the user has already pre-answered the clarifying questions in their prompt.

Engine: UE5.7. Platform: PC (Steam/Epic). Stage: Concept → GDD authoring (as of 2026-05-09).
