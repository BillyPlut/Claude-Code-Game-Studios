User arrives with design intent pre-formed and asks for adversarial critique, not co-creation. When the user presents "decided facts" + a specific request (gaps, anti-patterns, degenerate strategies, tradeoff questions), skip the question-first ideation workflow and go directly to the analysis.

**Why:** The user has a strong design background and has already done the first-pass thinking. Asking clarifying questions they've already answered wastes their time. They want a second brain that catches what they missed, not a collaborator that re-opens settled decisions.

**How to apply:** When the user provides a structured brief with decided facts and a specific deliverable (e.g., "flag gaps," "anti-patterns," "three tradeoff questions"), treat it as a design review task. Deliver the analysis directly. Only ask questions if a genuine ambiguity would change the analysis.
